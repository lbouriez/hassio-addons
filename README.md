# hassio-addons
Repository of custom addons for hass.io

## Codex

Run OpenAI Codex from the Home Assistant sidebar to inspect and maintain your
configuration, with persistent authentication and optional Home Assistant MCP.

- [Source repository](https://github.com/lbouriez/ha.addon.codex)
- [Documentation](codex/DOCS.md)
- Prebuilt images for AMD64 and ARM64.

## Plex
Plex media server forked with NAS integration  
Forked from: https://github.com/dianlight/addon-plex

## Tiny-RSS
Free and open source web-based news feed
